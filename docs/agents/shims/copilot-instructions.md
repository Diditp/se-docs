# GitHub Copilot instructions

This repository's engineering rules for AI agents live in `AGENTS.md` at the repository root.
Before generating or changing code:

1. Read `AGENTS.md` and follow its Working Agreement, routing table, and Definition of Done.
2. Read the domain rule file it routes to for the files you are editing (`docs/agents/<domain>/AGENTS.md`).
3. Always apply `docs/agents/security/AGENTS.md` when touching authentication, tokens, secrets, input handling, or personal data.

Do not duplicate rules here; update `AGENTS.md` or the domain rule files instead.
